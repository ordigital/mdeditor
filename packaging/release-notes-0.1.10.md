## Changes

- Searchable PDF export (Ctrl+Shift+E) and printing (Ctrl+P), including the Linux print-portal fix.
- Contextual formatting popup after selecting text, with four square buttons per row. Normal text (P) comes first; link and highlight use chain and marker icons.
- Color emoji picker (Ctrl+~) with larger icons, scrolling and live search in all 23 UI languages, plus English keywords.
- Color emoji in the editor and exported PDFs; bundled fonts work without system emoji fonts.
- Updated translations and bundled font/data licenses.

## Downloads

- Linux x86_64: AppImage built on Ubuntu 22.04 (glibc 2.35 or newer).
- Windows x86_64: portable ZIP; extract and run MDEdit.exe.
- SHA-256 checksum files are provided for both downloads.

## Validation and limits

90 tests passed; 3 manual benchmarks ignored. Formatting, Clippy and package integrity checks passed. Fresh Linux and Windows release builds completed. Native printing and Windows runtime were not tested interactively. Linux printing needs a working desktop print portal; Windows printing needs a registered PDF application supporting the Print verb.
