## Changes

- PageUp and PageDown move the cursor and view by one page in the editor; Shift extends the selection.
- The selection popup has a separator and clipboard icons: Copy, Paste with formatting, Paste as plain text.
- Ctrl+V pastes clipboard HTML converted to Markdown (plain text when no HTML is present); Ctrl+Shift+V pastes plain text.
- New UI strings translated into all 23 languages.

## Downloads

- Linux x86_64: AppImage built on Ubuntu 22.04 (glibc 2.35 or newer).
- Windows x86_64: portable ZIP; extract and run MDEdit.exe.
- SHA-256 checksum files included for both packages.
